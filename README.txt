Hive Planner iPhone PWA

Install on iPhone:
1. Upload this folder to HTTPS hosting, such as GitHub Pages, Cloudflare Pages, Netlify, or your own site.
2. Open the hosted index.html link in Safari on iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Open Hive Planner from the home-screen icon.

Note: iPhone cannot fully install a PWA from a random local file in the Files app. It needs to be opened from Safari over HTTPS for proper home-screen/offline app behavior.
